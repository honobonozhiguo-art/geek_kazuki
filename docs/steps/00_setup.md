# Step 0. セットアップ

## ゴール
- Flask アプリが `http://localhost:5000` で起動して "やったー" が見える
- `uv sync` で依存が入る

## 受講生がやること

```bash
# 1. 依存インストール
uv sync

# 2. アプリ起動
uv run flask --app app run
# → http://localhost:5000 で "やったー" が見える
```

これだけ。**次は Step 1 のデータ作成から**。

## 補足: なぜ Flask なのか

要件書 §5 の通り、Step 4 で LLM API キーを扱う時に、ブラウザにキーを露出させないためサーバーが必要。フロントだけで作ると誰でもキーを閲覧できてしまう。**これが本課題でバックエンドを設ける理由**であり、プレゼンで説明できるようにしておく。

Step 3 までは LLM を使わないので、この理由は Step 4 で初めて活きる。今の時点では「そういうものだ」と思っておけば OK。

## 補足: `uv` とは

Python のパッケージマネージャ。`pip` の代わりだと思えばよい。

- `uv sync`: `pyproject.toml` に書かれた依存を仮想環境にインストール
- `uv run <コマンド>`: 仮想環境の中でコマンドを実行
